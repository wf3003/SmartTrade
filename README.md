# SmartTrade (量策)

AI 驱动的数字货币合约自动交易系统。基于**技术指标入场质量评分** + **DeepSeek AI 方向复核** + **规则引擎风控**，支持多交易所、多币种、全自动运行。

## 特性

### 核心架构
- **六类行情分级**：强趋势多/空 → 弱趋势多/空 → 震荡偏多/空 → 纯震荡，每级不同杠杆和入场策略
- **入场质量评分**：RSI / BB / EMA / 动量 / 成交量五大维度，独立于 AI 判断，硬拦截时机差的信号
- **AI 方向复核**：DeepSeek 每周期校验策略信号方向，不一致时跳过
- **多周期回测策略选择**：实时扫描 5m/15m/30m/1h/4h，在反转与延续策略之间自动择优
- **逐层级联过滤**：回溯 → AI 评分 → 行情质量 → 入场质量，每层输出日志，可追踪拦截原因

### 风控体系
- **ATR 动态止损**：基于 1h ATR 自适应，默认 2.0x，范围 [2%, 8%]
- **ATR 跟踪止盈**：峰值利润按 ATR × 杠杆 × 1.5 动态跟踪，最低保留峰值 10%
- **固定回撤保护**：峰值浮盈回撤超过 25% 时全平锁利（可配置）
- **盈利回吐保本**：曾到过 ≥5% 峰值后转亏，自动全平
- **入场质量硬阻断**：方向评分 < 35 不开仓（参数热加载）
- **超涨超跌保护**：ATR 多倍偏离 + RSI 极端时拦截同方向信号
- **连败暂停**：连续 3 次亏损暂停该币种 30 分钟
- **递增冷却**：止损冷却递增（30 分 → 1 小时 → 4 小时）
- **仓位最小值保护**：无论多少层削减，仓位不低于 basePct / 4

### 自动优化
- **AI 交易复盘**：每 N 个周期自动调用 DeepSeek 分析已平仓交易，输出评分校准和参数调整建议
- **拦截参数自动调整**：AI 复盘可直接修改 intercept_params（如 entry_quality_min、ai_score_min）
- **优化规则引擎**：基于历史 snapshots 分值区间统计，自动生成 opt_role 规则
- **行情变迁检测**：ADX 趋势变化 > 30% 时清空旧规则重新学习

### 数据
- **流水账数据库**：部分平仓 INSERT 新记录，不改原记录，防交易所 sync 误重建
- **实时仪表盘**：Web 界面展示持仓、决策、交易记录
- **多交易所**：支持 OKX、Gate.io、Binance（含模拟盘）

## 快速开始

```bash
# 安装
npm install

# 配置（编辑 .env 填入 API 密钥和交易参数）
cp .env.example .env

# 启动（开发模式，自动重载）
npm run dev

# 或编译后启动
npm run build && npm start
```

## 入场质量评分

独立于 AI 的技术面入场时机判断，基于 1h + 1d 两个时间框架：

| 维度 | 影响 | 可调参数 |
|------|------|---------|
| RSI 极端位 | 逆势追空/追多扣分 | eq_rsi_* 系列（8 个） |
| Bollinger Band 位置 | 触及轨道时方向调整 | eq_bb_* 系列（8 个） |
| EMA 方向 | 顺 EMA 方向加分，逆方向扣分 | eq_ema_up_lb/sp |
| K 线实体质量 | 大阳/大阴对方向的提示 | eq_body_* |
| 成交量确认 | 放量突破/假动作识别 | eq_vol_* |
| 动量衰减 | ADX 高但多周期 EMA 方向分化时减分 | eq_momentum_decay_p |

所有参数通过 intercept_params 热加载，修改即时生效，无需重启。

## 仓位削减链

每个信号经过多层削减确定最终仓位：

```
1. AI 置信度    → < 50 减至 1/4, < 70 减半
2. 行情质量     → < 40 ×0.4, < 70 ×0.6
3. 入场质量     → < (阈值+20) 减半
4. 历史胜率乘数 → 高胜率放大，低胜率缩小
5. 优化规则     → opt_rules 仓位乘数
6. 最小值保护   → 不低于 basePct / 4
```

## 风控规则

- **止损**：ATR × 2，范围 [2%, 8%]
- **跟踪止盈**：trail_pnl_atr_mult: 1.5 — 峰值 − max(ATR% × 杠杆 × 1.5, 峰值 × 10%)
- **回撤保护**：profit_protect_retrace_pct: 25% — 峰值回撤 25% 全平
- **入场阻断**：entry_quality_min: 35 — 方向评分 < 35 不开仓
- **止损冷却**：首次 30 分钟，第二次 1 小时，第三次+ 4 小时
- **连败上限**：max_consecutive_losses: 3 — 连续亏损 3 次暂停 30 分钟
- **账户止损**：权益 ≤ $500 停止开新仓

## 配置文件 (.env)

主要配置项：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| EXCHANGES | okx | 交易所（逗号分隔） |
| BASE_POSITION_PCT | 20 | 每笔开仓百分比 |
| DEFAULT_LEVERAGE | 6 | 默认杠杆倍数 |
| SYMBOLS | BTC,ETH,... | 交易币种列表 |
| AI_MODEL | deepseek-v4-pro | AI 模型 |
| PORT | 3100 | 仪表盘端口 |

## 技术栈

- TypeScript + Node.js + tsx
- ccxt（交易所统一接口）
- DeepSeek API（AI 方向复核 + 交易复盘）
- better-sqlite3（本地存储，WAL 模式）
- Express（Web 仪表盘）

## 数据库表

| 表名 | 用途 |
|------|------|
| trades | 交易记录（流水账模式） |
| decisions | AI 决策记录（含 raw_response） |
| account_snapshots | 账户权益快照（每 5 秒） |
| exchange_orders | 交易所订单同步 |
| indicator_snapshots | 开仓时刻指标快照 |
| ai_reviews | AI 复盘记录 |
| intercept_params | 热加载拦截/风控参数 |
| opt_rules | 优化规则（胜率加权） |
| rule_performance | 规则漂移检测 |
| backtest_logs | 回溯日志 |
